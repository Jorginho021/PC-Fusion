# PC-Fusion

Descrição do Projeto

O PC Fusion é um site interativo que ajuda usuários a montar computadores de forma prática e segura, verificando a compatibilidade entre as peças escolhidas. O sistema abrange desde PCs básicos até setups gamer de alto desempenho, fornecendo feedback instantâneo sobre CPU, placa-mãe, RAM, GPU, SSD e fonte.

O objetivo do projeto é evitar erros na montagem e garantir que todas as peças funcionem em harmonia, tornando a experiência de montar um PC mais simples e confiável.

Funcionalidades

Seleção de CPU, placa-mãe, RAM, GPU, SSD e fonte através de menus interativos.

Verificação automática de compatibilidade entre as peças.

Mensagens visuais com cores e ícones:

✅ Verde → compatível

❌ Vermelho → incompatível

Suporte a builds básicos, intermediários e gamers.

Design moderno, responsivo e estilo gamer.

Tecnologias Utilizadas

HTML5 – Estrutura das páginas e formulários.

CSS3 – Estilo moderno com gradientes, neons e animações.

JavaScript (JS) – Lógica de compatibilidade dinâmica.
